## Webinar Overview

### Description

Most engineering work isn't greenfield. It's wrestling with code someone else wrote years ago. This session covers how to point AI tools at existing, messy, under-documented codebases and make real modernization progress without breaking what already works.

### Agenda

- Why brownfield is harder for AI than greenfield: missing context, implicit constraints, and accumulated tech debt
- Using AI to understand unfamiliar code: mapping architecture, tracing dependencies, and generating missing documentation
- Building a safety net first: characterization tests and coverage before refactoring legacy code
- Incremental modernization patterns: strangler fig, targeted refactors, and dependency upgrades with AI assistance
- Practical workflows for translating, untangling, or rewriting legacy modules while preserving behavior
- Knowing the limits: when to trust the agent, when to intervene, and when legacy code should be left alone
